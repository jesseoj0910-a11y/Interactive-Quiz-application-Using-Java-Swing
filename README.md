# Interactive Quiz Application Using Java Swing

## Project Description
A desktop-based interactive quiz application developed using Java Swing.

## Features
- 10 multiple-choice questions
- One question displayed at a time
- Radio-button answer selection
- Next/Finish navigation
- Score calculation
- Percentage calculation
- Restart quiz option
- Simple Swing GUI

## Requirements
- Java JDK 8 or later

## How to Run

### Windows
Open Command Prompt in the project folder and run:

```text
javac -d out src/InteractiveQuiz.java
java -cp out InteractiveQuiz
```

### Eclipse / IntelliJ IDEA / NetBeans
Create/import a Java project, add `src/InteractiveQuiz.java`, and run the `main()` method.
